Hundir la flota

Juego de Hundir la flota en Python para jugar por terminal contra la máquina. Proyecto del bootcamp de Data Science & AI de The Bridge.

Cómo funciona

Jugador y contrincante tienen un tablero (matriz de NumPy) con barcos escondidos. Se turnan para disparar; la máquina dispara de forma aleatoria. Gana quien hunde antes la flota del rival.

Estructura

main.py: flujo del juego y turnos.
funciones.py: funciones del juego.
variables.py: constantes y parámetros.
